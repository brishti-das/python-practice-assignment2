
# Python Practice Problems

This repository contains my Python practice problems and solutions.

## Problems

### Problem 1: Student Grade Calculator
- Takes student name and marks for 3 subjects.
- Calculates total and average marks.
- Determines the grade based on average marks.
- Uses Function, List, Dictionary, Loop and f-string.

### Problem 2: Simple Shopping Cart
- Takes customer name and 3 product names and prices.
- Calculates subtotal, discount and final total.
- Determines discount based on subtotal.
- Uses Function, List, Dictionary, Loop and f-string.
